КРАТКАЯ ПАМЯТКА ПО СИНТЕТИЧЕСКИМ ЭКСПЕРИМЕНТАМ
=============================================

Главные файлы
-------------

1. synthetic_api.py
   Основной файл с функциями.

2. synthetic_control_panel.ipynb
   Удобная тетрадь Jupyter для ручного запуска опытов.


Общая схема работы
------------------

Опыт строится по шагам:

1. создается исходная матрица;
2. при необходимости к ней добавляется структура;
3. строится поле пропусков;
4. из этого поля получается маска наблюдаемых элементов;
5. наблюдаемые элементы делятся на обучающую, проверочную и тестовую части;
6. добавляется шум;
7. все собирается в один объект Scenario;
8. на этом объекте запускаются методы;
9. считаются ошибки, строятся таблицы и рисунки.


Какие настройки задаются
------------------------

Вся задача собирается через ScenarioConfig.

Внутри него есть шесть частей:

- matrix              — размер, ранг, тип матрицы;
- structure           — дополнительная структура;
- missingness_field   — форма пропусков;
- mask_sampling       — доля наблюдаемых элементов;
- split               — доли проверочной и тестовой частей;
- noise               — шум.


Самый простой запуск
--------------------

1. Открой synthetic_control_panel.ipynb
2. Измени нужные настройки
3. Выполни ячейки по порядку
4. Сначала посмотри на матрицу и маски
5. Потом запускай методы


Как собрать один сценарий вручную
---------------------------------

Нужные функции:

- generate_base_matrix(...)
- apply_structure(...)
- build_missingness_field(...)
- sample_observed_mask(...)
- split_observed_mask(...)
- build_observed_matrix(...)
- package_scenario(...)

Идея такая:

1. создаем матрицу;
2. строим поле пропусков;
3. получаем маску;
4. делим маску на части;
5. собираем наблюдаемую матрицу;
6. упаковываем все в Scenario.


Как запустить методы
--------------------

Методы задаются через make_method(...).

Примеры:

- make_method('soft_impute', rank=4, max_iter=80)
- make_method('als', rank=4, max_iter=50, reg=1e-3)
- make_method('rgd', rank=4, max_iter=120)
- make_method('rgd_l2', rank=4, max_iter=120, l2_reg=0.03)
- make_method('compact_rgd', rank=4, max_iter=100)
- make_method('compact_l2_selected', rank=4, max_iter=90, l2_grid=[1e-3, 3e-3, 1e-2, 3e-2])

После этого:

- run_experiment_on_scenario(scenario, methods)

или

- run_single_experiment(config, methods, seed=42)


Как менять один параметр
------------------------

Если хочется понять влияние одного параметра, удобнее всего делать перебор.

Готовая функция:

- one_factor_sweep(base_config, parameter_path, values, methods, seeds)

Примеры путей:

- 'matrix.rank'
- 'missingness_field.mode'
- 'matrix.coherence_mode'
- 'noise.std'


Как получить таблицу
--------------------

После запуска:

- result.records

Если запусков несколько:

- records = collect_records(runs)

Далее:

- summary = aggregate_records(records, by=['method'])

или, например:

- summary = aggregate_records(records, by=['matrix.rank', 'method'])


Как построить рисунок
---------------------

Есть готовые функции:

- plot_matrix(...)
- plot_mask(...)
- plot_metric(...)
- plot_histories(...)

Обычно полезно сначала смотреть:

- истинную матрицу;
- поле пропусков;
- маску наблюдений;
- сходимость методов.


Как сохранить результаты
------------------------

- write_csv(...)
- write_latex_table(...)

То есть можно сразу сохранить:

- исходные результаты в csv;
- сводную таблицу в csv;
- таблицу для LaTeX.


Что лучше использовать сейчас
-----------------------------

Для новых опытов лучше брать:

- synthetic_api.py
- synthetic_control_panel.ipynb

Старые файлы можно не трогать, но они уже не главный путь работы.


Если хочется начать совсем просто
---------------------------------

Лучший порядок такой:

1. взять матрицу 60x60;
2. поставить rank=4;
3. взять mode='random';
4. поставить observed_fraction=0.35;
5. взять noise std=0.02;
6. сравнить soft_impute, rgd и rgd_l2;
7. потом уже менять только один параметр за раз.
